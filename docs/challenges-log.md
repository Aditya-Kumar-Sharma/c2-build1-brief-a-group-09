## The entry we are proudest of

Entry 4. A table printed H2 2025 as 0 and growth as "inf", and our first thought was that the data had no second half. The cleaned file actually covers 18 months, so that could not be right. Counting rows per month and then tracing the variable back through the earlier steps showed that an earlier cell had overwritten our main table with a filtered copy, so the rows were gone before the table was built. The data was fine and the bug was ours. We learned to keep the full table untouched, to print row counts before trusting any growth figure, and that a surprising zero is a question about our own code before it is a finding about the business.
